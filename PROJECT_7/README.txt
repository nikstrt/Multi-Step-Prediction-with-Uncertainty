======================================================================
ΟΔΗΓΙΕΣ ΕΚΤΕΛΕΣΗΣ ΚΩΔΙΚΑ: Multi-step Prediction with Uncertainty
======================================================================

Το παρόν έγγραφο περιγράφει τα βήματα που απαιτούνται για την επιτυχή εκτέλεση και αξιολόγηση του κώδικα της εργασίας. 
--- Βήμα 1: Παραγωγή και Προεπεξεργασία Δεδομένων ---
Πριν την εκπαίδευση ή αξιολόγηση οποιουδήποτε μοντέλου, είναι απαραίτητη η δημιουργία του συνόλου δεδομένων. 
Εκτελέστε το αρχείο παραγωγής δεδομένων (π.χ. data_pipeline.py ή το αντίστοιχο script που περιέχει τη συνάρτηση στοχαστικής συλλογής). Η διαδικασία αυτή συλλέγει τις μεταβάσεις από το περιβάλλον CartPole και δημιουργεί το αρχείο cartpole_stochastic_transitions.csv, το οποίο είναι προαπαιτούμενο για τα επόμενα βήματα.

--- Βήμα 2: Παραμετροποίηση του Κεντρικού Αρχείου (Main) ---
Όλος ο έλεγχος των πειραμάτων (αρχιτεκτονική, τύπος εκπαίδευσης, επιλογή τροχιάς) γίνεται κεντρικά. 
Ανοίξτε το αρχείο της κύριας ροής (main.py) και εντοπίστε την ενότητα CENTRALIZED CONTROL KNOBS στην αρχή του κώδικα. Εκεί, μπορείτε να ορίσετε (hardcode) τις υπερπαραμέτρους της αρεσκείας σας:

- TRAIN_MODE: Ορίστε True για να εκπαιδεύσετε τα μοντέλα από την αρχή, ή False για να φορτώσετε τα ήδη εκπαιδευμένα βάρη (Evaluation Mode).
- MODEL_MODE: Ορίστε τον τύπο του μοντέλου, επιλέγοντας ανάμεσα σε "deterministic" και "probabilistic".
- PROB_TYPE: Εφόσον το MODEL_MODE είναι πιθανοτικό, ορίστε "single" για το απλό νευρωνικό ή "ensemble" για την αρχιτεκτονική Deep Ensemble.
- TARGET_TRAJECTORY_ID: Εισάγετε το ID της τροχιάς (π.χ. 250) για την οποία θέλετε να παραχθούν τα αναλυτικά συγκριτικά διαγράμματα. (Ο κώδικας διαθέτει μηχανισμό ασφαλείας: αν το ID δεν ανήκει στο αυστηρά απομονωμένο Test Set, θα επιλεγεί αυτόματα ένα έγκυρο τυχαίο ID).

Μην ξεχάσετε να αποθηκεύσετε το αρχείο μετά την αλλαγή αυτών των παραμέτρων.

--- Βήμα 3: Εκτέλεση και Αποτελέσματα ---
Αφού αποθηκευτούν οι ρυθμίσεις στο main αρχείο, το μόνο που χρειάζεται είναι να ανοίξετε ένα τερματικό (ή command prompt) και να το εκτελέσετε:

python main.py

Τι να περιμένετε κατά την εκτέλεση:
1. Στο τερματικό θα εκτυπωθούν αναλυτικές πληροφορίες για τον διαχωρισμό των δεδομένων (χωρίς διαρροή πληροφορίας / leak-proof) και πίνακες με τη χρονική εξέλιξη του σφάλματος (MSE) και της αβεβαιότητας (Variance) για τον επιλεγμένο ορίζοντα.
2. Όλα τα παραγόμενα διαγράμματα (συγκρίσεις τροχιών, Monte Carlo Fan Charts, και καθολικά Totality Plots) θα αποθηκευτούν αυτόματα στον φάκελο outputs/. Τα αρχεία χρησιμοποιούν δυναμική ονοματολογία (suffixes) ώστε να μην αντικαθίστανται όταν εναλλάσσετε τις παραμέτρους (π.χ. από single σε ensemble).
